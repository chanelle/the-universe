# The Universe — SPARK Creative OS

A spatial creative operating system for high-volume, non-linear thinkers.

Most idea tools are lists. The Universe is a sky. Every idea you snag becomes a star in one of eight constellations — sized by leverage, brightened by maturity, dimmed when parked. You work it in the SPARK rhythm:

**Snag · Place · Assess · Refine · Kickoff**

The promise: *nothing gets lost, not everything becomes urgent.*

## v0.2 — The Observatory

- Universe view: an SVG star map with the eight constellations at fixed anchors
- Constellation zoom, star-travel animation when a spark gets Placed
- An "outskirts" band for unmapped snags, so new ideas have somewhere to land
- Confirmed spark-links drawn between related stars
- Every star is keyboard-focusable, with an on-screen legend
- Current focus gets a gold halo
- Reduced-motion safe

## Run it

It's one file. Open `universe.html` in a browser — no build, no server, no account. Your sparks are stored locally in your browser, on your device.

## Status

Early and personal: this is the working prototype of a system built for one nonlinear brain, shared in case yours works the same way.
